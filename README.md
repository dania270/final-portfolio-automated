# Dania Khan — AI Automation & AI Agent Developer Portfolio

A premium, dark, futuristic personal portfolio website built with plain HTML, CSS and JavaScript.

## Structure

```
portfolio/
├── index.html      # All page structure and sections
├── style.css       # All styling (variables, sections, responsive)
├── script.js       # Navbar, mobile menu, scroll reveal, particles, form
├── assets/
│   ├── images/
│   └── icons/
└── README.md
```

## Run locally

Open `index.html` in VS Code and click **Go Live** (Live Server extension), or just double-click the file in your browser.

## Colors (CSS variables in `style.css`)

```css
:root {
  --black: #050505;
  --dark:  #080808;
  --pink:  #ff1493;
  --blue:  #00a8ff;
  --white: #ffffff;
}
```

## Things to replace

- Email: `your-email@example.com`
- GitHub: `https://github.com/your-username`
- LinkedIn: `https://linkedin.com/in/your-profile`
- Project links: currently point to the contact section
- Hero stats (`15+`, `6`, `24/7`) in the hero section
- Contact form: connect the submit handler in `script.js` to your email service (Formspree, n8n webhook, etc.)
